Documentación del Proyecto
1. Descripción del Proyecto
Este proyecto es un blog estático construido con Angular (frontend) y Node.js (backend). Permite a los usuarios crear y visualizar posts, que se almacenan como archivos Markdown en la carpeta assets/posts. Los posts se pueden organizar y mostrar en la página de inicio.

Características principales
Frontend (Angular):

Página de inicio que muestra una lista de posts.

Página de detalles para ver un post completo.

Dashboard para agregar nuevos posts.

Backend (Node.js):

API para guardar nuevos posts como archivos Markdown.

API para actualizar la lista de posts en home-data.json.
